# Materiale didattico aggiuntivo

Raccolta di dispense e guide di supporto per lo studio e le esercitazioni di
Laboratorio di Calcolo.

## Documenti

- [Prontuario del Laboratorio di Calcolo](Prontuario_Lab_Calc.pdf) - Riferimento rapido per le attività del laboratorio.
- [Dispense di esercizi per il corso di Laboratorio di Calcolo](Dispense_labcalc.pdf) - Raccolta di esercizi svolti, con soluzioni in C e script Python per i grafici.
- [UNIX: introduzione elementare](manuale-unix.pdf) - Guida introduttiva di Marco Liverani per principianti: sistema Unix, comandi fondamentali, editor, X Window e strumenti di rete.
